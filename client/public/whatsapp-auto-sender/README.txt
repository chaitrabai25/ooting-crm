OOTING CRM - 100% HANDS-FREE WHATSAPP WEB AUTO-SENDER EXTENSION
========================================================================

HOW TO INSTALL IN CHROME, EDGE, OR BRAVE IN 3 QUICK STEPS:

STEP 1:
In your browser address bar, type:
chrome://extensions   (for Chrome or Brave)
edge://extensions     (for Microsoft Edge)
and press Enter.

STEP 2:
In the top-right corner of the Extensions page, turn ON the "Developer mode" toggle switch.

STEP 3:
Click the "Load unpacked" button at the top-left corner, and select this folder ("whatsapp-auto-sender").

THAT'S IT! 
The Ooting Auto-Sender extension is now installed.

HOW IT WORKS:
Whenever you launch a WhatsApp Web broadcast in Ooting CRM, this extension:
1. Detects each client chat as it opens.
2. Waits 1.5 seconds for WhatsApp to initialize the message draft.
3. Automatically clicks the Send button without you touching the mouse!
4. The CRM then automatically advances to the next client in the list.
Zero manual clicking required!
